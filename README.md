# Fall of Nevermore

Publiczny, interaktywny dokument projektowy neogotyckiego larpa osadzonego w 1905 roku.

## Uruchomienie

```bash
npm install
npm run dev
```

## Cloudflare Pages

- Framework preset: **Astro**
- Build command: `npm run build`
- Build output directory: `dist`
- Production branch: `main`

Rozdziały edytuje się w `src/data/chapters.js`. Publiczne repozytorium nie powinno zawierać spoilerów organizatorskich ani prywatnych danych uczestników.
