# Historical art sources

The following artworks are historical reproductions, not AI-generated. Both originate from Gustave Doré's illustrations for Edgar Allan Poe's *The Raven* (Harper & Brothers, 1884).

1. **Doré, plate 12.** https://commons.wikimedia.org/wiki/File:Dore_The_Raven_1884-12.jpg — public domain; used as cover background.
2. **Doré, plate 22.** https://commons.wikimedia.org/wiki/File:Dore_The_Raven_1884-22.jpg — public domain; used in the introductory illustration panel.

Library of Congress edition and rights statement: https://www.loc.gov/item/12037813/ (Children's Book Selections: public domain and free to reuse).

The first import runs through GitHub Actions and saves JPEGs to `public/images/`. The website initially uses Commons image URLs and switches to local images when the files are available.
